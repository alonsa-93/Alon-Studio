# English UI and MCP for every op

## Two languages

- **Strings:** every text the studio shows is in `src/i18n.ts`, one key per string, `[Hebrew, English]`. `t(key, vars)` fills `{slots}`. The Hebrew is the text the UI had before, unchanged.
- **Lists in `shared/`:** transitions, animations, blend modes, eases, looks, caption and text styles (and their sample texts), export presets, default track names and the sound effects keep their Hebrew labels in `shared/` and `server/sfx.ts`, because the server uses them. The UI shows them with `tl(group, id, he)`, which takes the English from the strings file (`tr.fade`, `look.bw`, `sfx.whoosh`...).
- **Switch:** "EN" / "עב" in the top bar (`data-testid=lang-toggle`). It sets `lang` and `dir` on `<html>` (English is LTR, so the library and the inspector swap sides), keeps the choice in `localStorage` (`alon.lang`), and re-renders without reloading the project. The timeline and the player stay left to right in both languages.
- **Fonts:** Assistant for Hebrew, Inter for English (`:lang()` in `styles.css`).
- **Keyboard:** shortcuts read `e.code` (the physical key), so S, K, I, O, X and Ctrl+Z work with a Hebrew keyboard layout too.
- **Project content:** texts the studio inserts (a new title, a template's sample text) are in the UI language. Texts the user wrote are never translated.
- **Not translated:** messages made by the server (errors, job progress) are still Hebrew. See "Open items".

## MCP for every op

- Every op in `OP_NAMES` has its own MCP tool. The map is `OP_TOOLS` in `server/mcp-ops.ts`.
- New tools in this step: `move_clip`, `trim_clip`, `update_clip`, `duplicate_clip`, `ripple_delete`, `detach_audio`, `add_track`, `set_track`, `delete_track`, `set_settings`, `set_in_out`, `set_captions`, `set_caption_animation`, `remove_media`.
- Each one goes through the same op checks as REST (`POST /api/projects/:id/ops`).
- Every tool has `readOnlyHint` or `destructiveHint`. The tools that remove things (`delete_track`, `ripple_delete`, `remove_media`, `set_captions`) are destructive.
- The AI agent gets the new editing tools too, except `remove_media`.

## Tests

- **`scripts/i18n-check.ts`** (in gate 2):
  - every key has both languages and the same `{slots}`;
  - English has no Hebrew letters;
  - every shared list item and sound effect has an English entry whose Hebrew matches the list;
  - no Hebrew literal is left in the components, `App.tsx`, `store.ts` or `actions.ts` (comments excepted);
  - every `t('…')` key exists.
- **`scripts/e2e-mcp.ts`** (in gate 4): every op has a listed tool, every tool is annotated, and each new tool really edits a project. Bad input is refused (volume 9, 25 fps).
- **Browser (gate 6):** the whole journey runs twice, in Hebrew and with `UI_LANG=en`. In English, every label the journey clicks is looked up in the strings file, so the run clicks the real English labels. The English run saves its screenshots to `ui-out/en`.
